# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately**, never in a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and click
**Report a vulnerability**. The report is visible only to the maintainer.

Include, if you can:

- what is affected (endpoint, page or file) and what an attacker could do with it;
- steps to reproduce;
- the impact you see.

Reports are handled on a best-effort basis. Fixes are released first and disclosed afterwards.

## Supported versions

Only the current `main` branch, which is what the live demo runs, receives security fixes.
